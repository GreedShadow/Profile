04 / LAYOUT RATIONALE

Every layout
has a reason.

This page is also a study in choosing the right tool. Flexbox handles content that flows in one direction; Grid handles relationships across two.

01 Navigation Flexbox / 1D+

Dimensionality: A single horizontal row. Control: Content-first, with space distributed between the brand and links. Responsive plan: The row becomes a compact menu on small screens. Flexbox keeps this fluid with one breakpoint.

Trade-off: Grid would add unnecessary column tracks for a sequence that only needs alignment and pushing.

02 Hero Flexbox / 1D+

Dimensionality: Two content blocks flow side by side, then stack. Control: Content-first so the copy can grow naturally. Responsive plan: Alignment changes from row to column without repositioning individual items.

Trade-off: Grid could define exact columns, but would make the art and copy more rigid than the story needs.

03 Skills Grid / 2D+

Dimensionality: Cards need consistent relationships across rows and columns. Control: Layout-first equal tracks create a calm scan. Responsive plan: Auto-fit collapses columns fluidly.

Trade-off: Flex-wrap can make rows uneven and makes shared column alignment harder to maintain.

04 Projects Grid / 2D

Dimensionality: Varied cards need coordinated horizontal and vertical gaps. Control: Layout-first, with named spans for visual hierarchy. Responsive plan: The same grid becomes one column on mobile.

Trade-off: A flex layout would need width hacks to reproduce the intentional asymmetry.

05 Footer & contact Flexbox / 1D+

Dimensionality: Social links and copyright sit on opposite ends of one row. Control: Content-first, pushed apart with space-between. Responsive plan: It wraps into a column on narrow screens.

Trade-off: Grid would work, but adds tracks where one-axis distribution is the entire problem.
